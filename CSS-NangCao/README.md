## Mục tiêu

Thực hành luồng tài liệu, định vị, bố cục nhiều cột, giao diện responsive, hiệu ứng CSS và hệ thống lưới Bootstrap 3.

## Cấu trúc

- `index.html` và `style.css` tạo trang giới thiệu, mục lục và phần tự đánh giá.
- `Lab07/index.html` là mục lục các Exercise.
- `Lab07/Exercise01/` đến `Lab07/Exercise19/` chứa các trang thực hành. Bài 7.13 tiếp tục trên HTML và hai stylesheet desktop/mobile của bài 7.12.
- `Lab07/bootstrap/` và `Lab07/images/` chứa thư viện và tài nguyên từ bộ bài mẫu.

## Truy cập

Mở `index.html` bằng trình duyệt rồi chọn bài trong danh sách. Trên GitHub Pages, truy cập [trang CSS nâng cao](https://tranhuutuanbang.github.io/BaiTapBuoi1PTUDTMDT/CSS-NangCao/).

| Bài | Nội dung |
| --- | --- |
| 7.1–7.4 | Document flow, positioning và z-index |
| 7.5–7.9 | Float, clear và đặt chú thích chồng lên ảnh |
| 7.10–7.13 | Hai cột, ba cột, media query và viewport |
| 7.14–7.18 | Transforms, transitions, filters và animations |
| 7.19 | Bootstrap 3, lưới lồng nhau và các thành phần giao diện |

Thử mở 7.12/7.13 ở 480 px và 481 px để xem bố cục thay đổi. Rê chuột ở 7.15–7.17 để thử hiệu ứng. Tải lại 7.18 để xem animation từ đầu.
